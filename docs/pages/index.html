Step 5Interaction: report/chat API path

ZEP-free

GRAPH_PROVIDER는 기본적으로 Graphiti/Neo4j를 사용합니다. UI 표시는 내부 projection cache를 사용하지만 fallback provider는 제공하지 않습니다.

Compose-first

frontend/backend/graph-memory/Neo4j 등을 Docker Compose profile로 묶고, 모델 endpoint는 env로 교체합니다.

Mac-local embeddings

Jina/MLX/Metal embedding server는 Docker 외부 macOS host에서 띄우고, Graphiti가 host.docker.internal로 접근하는 구성을 권장합니다.

Local quickstart

git clone https://github.com/crimson-joo/mirofish-localized.git
cd mirofish-localized
cp .env.example .env
# Fill OpenAI-compatible LLM + embedding endpoints, then:
docker compose --profile graphiti up --build

Note: 이 GitHub Pages는 정적 확인/문서 페이지입니다. 실제 MiroFish UI Step1~Step5는 로컬 backend/model/Graphiti stack이 필요합니다.
